This is a repository for the new-retro single board computer [Altaids](https://www.nutsvolts.com/magazine/article/build-a-pocket-sized-altair-computer), designed by David Hunter. 

The Altaids is a single-board reimagining of the Altair 8080, running on the ever-so-slightly more modern Intel 8085, running at 2.5MHz with 8KB ROM and 8KB RAM. It has its own assembly monitor, its own variant of Palo Alto Tiny BASIC, and can save/load files via its terminal connection.

Oh -- and it fits inside of an Altoids tin.

Mostly, this is a place for me to store programs that I write for it.
